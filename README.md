# GeoTank

A real-time multiplayer 2D tank game written in Java with LibGDX and KryoNet. Players join lobbies, fight in a procedurally generated arena and level up their tanks by destroying opponents and obstacles.

Built in 2026 as a team project for the *Software Development Project* course (ITI0301) at Tallinn University of Technology.

## Gameplay

You drive with the keyboard and aim your cannon with the mouse. Destroying opponents and static shapes earns XP. Each level-up gives a point to spend on health, regeneration, movement speed, bullet damage or bullet penetration. Certain levels unlock new tank classes with different weapons and firing patterns, so each match can follow a different upgrade path.

**Features**
- Online multiplayer with public and private lobbies (join by code), ready-up and joining a match already in progress
- Server-controlled AI tanks, with a per-lobby limit on how many there are
- XP, levels, stat upgrades and unlockable tank classes
- Procedurally generated arena with destructible objects
- HUD with a minimap, XP bar and skill panel
- In-lobby chat, and a settings screen with audio controls

### Controls

| Action | Key |
|---|---|
| Move | Arrow keys or WASD |
| Aim | Mouse |
| Fire (hold to keep firing) | Space |
| Upgrade a stat | Number keys |
| Chat in lobby | C to type, Enter to send |
| Menu / back | Esc |

## Architecture

The project is a Gradle multi-module build:

```
shared/            network messages, constants, the TCP/UDP transport layer (used by client and server)
server/            authoritative game server: lobbies, game loop, combat, AI tanks, XP
client-core/       LibGDX game client: screens, rendering, HUD, audio, view models
desktop-launcher/  LWJGL3 desktop entry point for the client
```

**Networking**
- **Server-authoritative combat.** The server resolves every hit, the damage, XP and deaths, and then sends the results to the clients. A modified client can't award itself kills.
- **TCP and UDP.** Messages that must arrive, such as lobby actions and chat, go over TCP. Frequent tank updates go over UDP, so one lost packet never stalls the game.
- **Message protocol.** Every message is a plain serialisable class registered with KryoNet. The lobby and game protocol is documented in [`network.md`](network.md).

## Running it

**Requirements:** JDK 21 or newer. The Gradle wrapper is included, so nothing else needs installing.

```bash
# Terminal 1: start the server (TCP 8080, UDP 8081)
./gradlew :server:run

# Terminal 2: start a client (repeat in more terminals for more players)
./gradlew :desktop-launcher:run
```

The client connects to `localhost` by default. If another program already uses port 8080 (Jupyter Notebook does by default), change `PORT_TCP` in the same file. To play over a network, change `SERVER_IP` in [`shared/.../constant/Constants.java`](shared/src/main/java/ee/taltech/wiseones/geotank/shared/constant/Constants.java) and rebuild.

To build everything:

```bash
./gradlew build
```
